DFA INTERSECT - WINDOWS EXE (ONE-GO BUILD)

1. Extract this project into D:\DFA_INTERSECT\dfa-intersect (or keep your chosen project folder).
2. Install Node.js LTS from https://nodejs.org/ if it is not already installed. Restart Windows/terminal after installation if needed.
3. Double-click BUILD-EXE.bat. Allow it to finish; the first build needs internet and may take a few minutes.
4. The portable Windows EXE will be created in the release folder.

Important: build the EXE on Windows. You do not need Java or Maven for this React/Vite project.
If Windows SmartScreen warns about an unsigned app, only run it if you trust the project you built.
